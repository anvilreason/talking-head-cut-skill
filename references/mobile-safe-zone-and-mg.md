# 竖屏手机端防遮挡安全区与 MG 视觉验收清单

本参考手册用于确保 `1080×1920`（9:16）竖屏口播视频在抖音、小红书、视频号等手机端真机播放时，所有 MG 动效、评分条、字幕与情绪暴击条 **100% 不被平台 UI 遮挡**，且保持高信息密度与清晰观感。

---

## 二、 批量制作 MG 后的逐帧自检清单（Checkpoint 3）

在交付成片前，按以下 8 项逐段抽帧核查：

- [ ] **顶部防遮挡**：所有顶部标题、评分 HUD、卡片的最高边缘是否都在 `y >= 260px` 以下？
- [ ] **右侧与底部避让**：核心文字是否避开了右侧互动栏（`x >= 930px`）与底部简介区（`y >= 1580px`）？
- [ ] **真实官方 Logo**：提到的所有品牌/软件是否全部使用了真实官方 Logo，零手画假图标？
- [ ] **全程露脸与及时撤场**：重磅图表是否采用透明悬浮布局避免长时间挡脸？切换话题时上一主题图表是否立刻撤场？
- [ ] **严格逐词卡点**：是否做到“说到哪词才跳哪词”，没有任何提前剧透的结论、产品名或反转金句？
- [ ] **掉血/进度动效干脆**：涉及额度消耗/掉血动画是否在 `1.2 - 1.8 秒` 内急剧完成，无拖拉感？
- [ ] **单行整句字幕零错字**：字幕是否严格按中文语义整句断句（无 2 - 3 字碎片）？英文专有名词是否 100% 拼写正确？
- [ ] **提示音音量克制**：关键节点 SFX（Pop / Ding / Whoosh / Alert）是否控制在 `-14 dB` 到 `-16 dB`，不压人声？
